# Przygotowanie środowiska

## Cel

Celem tej części jest przygotowanie środowiska warsztatowego oraz danych wykorzystywanych podczas ćwiczeń.

## Kroki

1. Pobierz najnowszą wersję repozytorium.
2. Otwórz SQL Server Management Studio.
3. Połącz się z instancją SQL Server 2025.
4. Wykonaj skrypt:

```sql
sqlserver2025-tsql-regex00-SETUP.sql
```

5. Zweryfikuj poprawność utworzenia obiektów.
