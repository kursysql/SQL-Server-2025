# Warsztaty: Wyrażenia regularne w SQL Server 2025

## Wprowadzenie

SQL Server 2025 wprowadza natywne wsparcie dla wyrażeń regularnych (Regular Expressions).

Podczas warsztatów poznasz nowe funkcje umożliwiające:

- wyszukiwanie danych tekstowych,
- walidację danych,
- czyszczenie i transformację tekstu,
- wyodrębnianie informacji,
- analizę danych półstrukturalnych.

Warsztaty mają charakter praktyczny i bazują na demonstracjach oraz samodzielnie wykonywanych ćwiczeniach.

## Wymagania

- SQL Server 2025
- AdventureWorks2025
- wykonanie skryptu:

```sql
sqlserver2025-tsql-regex00-SETUP.sql
```

## Agenda

### 01. Wyszukiwanie i walidacja danych

- REGEXP_LIKE
- REGEXP_INSTR
- REGEXP_COUNT

### 02. Czyszczenie i transformacja danych

- REGEXP_REPLACE

### 03. Wyodrębnianie informacji

- REGEXP_SUBSTR
- REGEXP_MATCHES

### 04. Praca z listami i analiza tekstu

- REGEXP_SPLIT_TO_TABLE
- scenariusze łączące wiele funkcji
